# -----------------------------------------------------------------------------
# Security Best Practices
# -----------------------------------------------------------------------------
# 1. Password Requirements:
#    - Minimum 6 characters (increase for production: 8-12 recommended)
#    - Consider adding complexity requirements (uppercase, lowercase, numbers, symbols)
#
# 2. JWT Token Security:
#    - Use strong secret key (256+ bits)
#    - Set appropriate expiration time
#    - Consider implementing token refresh mechanism
#    - Store tokens securely on client (httpOnly cookies or secure storage)
#
# 3. Role-Based Access Control:
#    - role = 0: Normal user (ROLE_USER)
#    - role = 1: Superuser (ROLE_SUPERUSER, ROLE_USER)
#    - role = 2: Admin (ROLE_ADMIN, ROLE_SUPERUSER, ROLE_USER)
#
# 4. HTTPS in Production:
#    - Always use HTTPS in production
#    - Configure SSL/TLS certificates
#    - Enable HSTS (HTTP Strict Transport Security)
#
# 5. Rate Limiting:
#    - Consider implementing rate limiting for auth endpoints
#    - Prevent brute force attacks
#
# 6. Input Validation:
#    - All DTOs include validation annotations
#    - Sanitize user input to prevent XSS
#    - Use parameterized queries (JPA handles this)
#
# 7. Database Security:
#    - Use strong database passwords
#    - Limit database user permissions
#    - Enable database audit logging
#    - Regular backups
#
# 8. Monitoring & Logging:
#    - Log authentication attempts
#    - Monitor for suspicious activity
#    - Set up alerts for failed login attempts
