================================================================================
NOTAS IMPORTANTES
================================================================================

✓ Las contraseñas están hasheadas en bcrypt en la base de datos
✓ El DatabaseSeeder se ejecuta automáticamente en el inicio
✓ El DataSeeder solo se ejecuta si la BD está vacía y tiene el perfil "seeder"
✓ El SeederService permite crear/actualizar datos manualmente
✓ Algunos usuarios pueden coexistir si se ejecutan diferentes seeders
✓ Para testing en desarrollo, usa las credenciales del Database Seeder
✓ Para testing completo con tests, activa el perfil "seeder"

================================================================================
CÓMO USAR EN DESARROLLO
================================================================================

1. Con Maven (perfil local sin tests adicionales):
   mvn spring-boot:run -Dspring-boot.run.arguments="--spring.profiles.active=local"

2. Con Maven (perfil local con tests adicionales):
   mvn spring-boot:run -Dspring-boot.run.arguments="--spring.profiles.active=local,seeder"

3. Con Docker (dev con tests adicionales):
   docker-compose -f devdoc/compose.yaml up

4. Loginear en frontend:
   - Email: admin@admin.com o user@user.com
   - Password: admin123 o user123
